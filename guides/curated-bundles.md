# Curated Bundles

Seventeen recipe cards is enough to need a starting point, especially if you're new here. A bundle isn't new content. It's a short page that groups existing [recipe cards](../recipes/README.md) around one common situation, so you don't have to read all seventeen to work out where your job sits.

I built these before any real use showed which groupings matter most, which is earlier than I'd usually publish something. Nothing below is an installer or a download. Each bundle is a page of links to files that already exist. A downloadable version of a bundle, for use outside this repository, is a separate idea in ROADMAP.md.
