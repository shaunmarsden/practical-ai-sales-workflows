# Fictional CRM Contact Export

> This is an entirely fictional CRM contact export, created to test the CRM Hygiene Review workflow. Every record, name and figure is invented. It uses a fresh cast rather than reusing the existing fictional companies, because it is a contact-level export with activity columns rather than the deal-level snapshot the [other fictional export](fictional-crm-export.md) provides.

This export lists contacts rather than deals, so it carries the activity that sits behind a record: whether a meeting was booked, whether it was attended, and how many calls and emails are logged.
